# A.2. Процессы POSIX

## Описание задачи

Реализовать интерактивную программу, принимающую команды от пользователя и выполняющую расчет площади покрытия методом Монте-Карло пересекающихся кругов заданных радиусов. Взаимодействие с пользователем и расчет площади должны выполняться в разных процессах. Для создания процессов и их взаимодействия должны быть использованы средства, описанные в стандарте POSIX. Работа должна быть выполнена в виде 1 исполняемого файла без параметров командной строки.

Задача основного процесса — обрабатывать команды, вводимые со стандартного ввода, отправлять запросы на расчет дочернему процессу и сохранять полученные результаты расчетов. Все расчеты должны выполняться в создаваемых дочерних процессах.

Программа должна поддерживать следующие операции:
- создание фигуры заданного радиуса с указанными координатами;
- создание набора из созданных фигур;
- просмотр созданных фигур и наборов;
- вычисление ограничивающего прямоугольника заданного набора или отдельной фигуры;
- выполнение запроса на расчет площади покрытия указанного набора;
- просмотр результатов завершенных расчетов;
- ожидание завершения указанного расчета.

Пользовательский интерфейс должен поддерживать следующие команды:

### `circle <name> <r> <x> <y>`
Создание круга с именем name радиуса `r` с координатами `x` и `y`. Команда считается ошибочной, если круг с данным именем уже существует или параметры некорректны.

### `set <name> <set-size> <shape-1> ... <shape-n>`
Создание набора с именем name из `set-size` фигур с указанными именами `shape-1...shape-n`. Команда считается ошибочной, если набор с заднным именем уже существует, некорректно задан размер набора или не существует какой-либо фигуры с заданным именем.

### `show <shape-name>`
Вывод параметров круга с именем `shape-name` на отдельной строке в формате `<radius> (<x> <y>)`. Например для ввода:
```
circle c1 5 3 4
show c1
```
Ожидается вывод:
```
5 (3 4)
```
Команда считается ошибочной, если фигуры с заданным именем не существует.

### `showset <set-name>`
Вывод каждого элемента набора с именем `set-name` на отдельной строке. Формат вывода соответ- ствует выводу команды show. Например для ввода:
```
circle c1 5 3 4
circle c2 10 0 0
set c1c2 2 c1 c2
showset c1c2
```
Ожидается вывод:
```
5 (3 4) 10 (0 0)
```

Команда считается ошибочной, если набора с заданным именем не существует.

### `frame <shape-name>`
Вывод ограничивающего прямоугольника для фигуры с именем `shape-name`. Например для ввода:
```
circle c2 3 0 0
frame c2
```
Ожидается вывод:
```
(−3 −3) (3 3)
```
Команда считается ошибочной, если круга с заданным именем не существует.

### `frameset <set-name>`
Вывод ограничивающего прямоугольника для набора с именем `set-name`. Формат вывода аналогичен команде `frame`. Например, для ввода:
```
circle c1 5 3 4
circle c2 10 0 0
set c1c2 2 c1 c2
frameset c1c2
```
Ожидается вывод:
```
(−10 −10) (10 10)
```
Команда считается ошибочной, если набора с заданным именем не существует.

Далее идут команды, связанные непосредственно с расчетами:

### `area-on <calc-name> <seed> <set-name> <threads> <tries>`
Запуск расчёта площади покрытия набором `set-name` с заданным числом потоков при количестве испытаний в методе Монте-Карло. `calc-name` является именем расчёта по которому можно получить результаты расчёта с зерном генерации `seed`. Все расчёты должны выполняться в отдельно создаваемом процессе. Таким образом на каждом процессе выполняется ровно один расчёт.

Команда считается ошибочной, если расчёт с заданным именем уже запускался или набор для расчёта не существует, или расчёт запустить не удалось по причинам, связанными деталями реализации

### `status <calc-name>`
Вывод статуса расчета с имемем `calc-name`. Для завершенного расчета должно выводиться через пробел: имя процесса, время расчета в милисекундах, полученное на вычисляющем процессе, и площадь покрытия. Числовые значения выводятся с точностью до трех знаков. Если расчет не завершен, должно быть выведено имя процесса, выполняющего расчет и через пробел сообщение `<IN PROGRESS>`. Команда считается ошибочной, если заданный расчет не запускался.

### `wait <calc-name>`
Ожидание завершения расчета с именем `calc-name`. Должны быть выведены результаты расчета в формате, описанном в команде `status`. Команда считается ошибочной, если заданный расчет не запускался.

Если команда ошибочна, должно выводиться сообщение `<INVALID COMMAND>`. При этом, если введено имя несуществующей команды, должно выводиться сообщение `<UNKNOWN COMMAND>`.

Каждая команда располагается на отдельной строке. Радиус кругов, координаты, количество испытаний и число потоков в методе Монте-Карло задаются целыми числами. Имена кругов, наборов, расчетов и процессов задаются строкой без пробелов, начинающейся с букв английского алфавита. Ввод команд должен завершаться `EOF`. Программа должна завершаться нулевым кодом возврата.

## Работа с проектом

Конфигурация, сборка и запуск отладочной сборки:
```
cmake --preset debug
cmake --build --preset debug
./build/debug/system-processes
```

## Загрузка работы

1. Выполненную работу в своем форке нужно загрузить в отдельную ветку.
2. Создать PR в свой `master` и запросить ревью у всех ревьюверов.
3. После проверки, если требуется, ответить на комментариии и поправить код.
4. Работа считается сданной когда все комментарии закрыты и PR заливается в основную ветку `master`.

В проекте рекомендуется использование гайдлайна по форматированию кода из `coding-guidelines.pdf`.

## Использование clang-format

### Применение форматирования

Находясь в корне репозитория (где лежит `.clang-format`), выполните:

```bash
clang-format -i $(find . -name "*.cpp" -o -name "*.h")
```

Команда отформатирует **все исходные файлы проекта** на месте (`-i` — in-place).

### Проверка без изменения файлов

Чтобы просто проверить соответствие без перезаписи:

```bash
clang-format --dry-run --Werror $(find . -name "*.cpp" -o -name "*.h")
```
